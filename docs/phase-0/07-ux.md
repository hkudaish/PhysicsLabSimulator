# UX / 3D interaction specification

Arabic is primary, English secondary. Proposed desktop workspace:

```text
┌──────────────────────────────────────────────────────────────┐
│  حفظ   استئناف   إعادة ضبط     غير متصل        تجربة التخفيف  │
├───────────────┬─────────────────────────────┬────────────────┤
│ قراءة القياس  │                             │ الأدوات        │
│ C = 0.5 mol/L │        طاولة المختبر         │ كأس / مخبار    │
│ الحجم 200 mL  │    glassware + pour target   │ ماء / محلول    │
│ خصائص الأداة  │                             │ خطوات التجربة  │
├───────────────┴─────────────────────────────┴────────────────┤
│ تم الحفظ محلياً      تراجع       تعليمات       الخطوة ٢ من ٥ │
└──────────────────────────────────────────────────────────────┘
```

This text wireframe specifies logical positions; Arabic shaping and visual ordering must be checked in the selected UI renderer. Equipment catalog on the right; inspector/measurements on the left; scene in the center; persistent status and action guidance. Explicit LTR isolation for `C = 0.5 mol/L`, `H₂O`, `I = V/R`, signed currents and units. Do not reverse a formula or rely on manually reversing Arabic strings. Bundle a licensed Arabic font after its license is reviewed.

Flow: select/resume experiment → read objective/model limitations → choose equipment → place safely → inspect/change quantity or component → pour/connect → observe measurements and explanation → save/reset/exit. Chemistry and electrical benches are separate work areas to avoid ambiguous gestures.

| Action | Mouse | Keyboard/accessibility equivalent |
|---|---|---|
| Select | Click; visible outline and label | Tab cycle; Enter select |
| Move | Drag selected tool; placement preview | Arrow-key nudge in placement mode; Enter commit; Esc cancel |
| Rotate | Dedicated handle/control | Q/E or labeled control |
| Camera | Right-drag orbit, wheel zoom within limits | Labeled orbit/zoom buttons; reset view |
| Pour | Select source/target, enter bounded volume, confirm | Same dialog through focus navigation |
| Wire | Select start terminal then end; preview | Terminal list navigation; Enter endpoints; Esc cancel |
| Undo/reset | Visible controls | Focusable controls; reset confirms loss of unsaved draft |
| Meter | Pick mode, connect probes, read units | Terminal picker and accessible text reading |

Initial pouring is a deliberate quantity action with visual tilt, not a collision-triggered uncontrolled transfer. Object movement constrained to valid bench bounds, non-overlap checks, visible invalid placement, no state mutation on cancelled drag. Wire endpoints use stable IDs, with enlarged selectable hit areas. Instruments read authoritative solver data. Display meaningful invalid/open/short diagnostics and suggested next action; color and sound are supplementary cues.

Save states: saving, saved locally, failed with retry/export, incompatible version requiring recovery. Exit warns only when the current state is not durably stored. Phase 2 adds queued/acknowledged/conflict/expired-license states. Expired licensing prevents new restricted sessions per approved policy without deleting saved work.

Teacher portal wireframe (Phase 2): RTL navigation at right for classes / assignments / results; class filter and search at top; central assignment table with experiment/version, due date and completion; learner detail includes provisional/verified result and event evidence. Institution view: campuses/labs/devices/seats/renewal; content workflow view separates author, scientific review, instructional review, QA and publisher permissions. No mock analytics should be presented as measured results.

Accessibility acceptance: visible focus; full keyboard operation; readable scaling; non-color errors; no essential information through sound alone; reduced motion/flash profile; manually checked Arabic terminology and mixed-direction numerals. Representative text/layout wireframes exist; interactive visual mockups and actual native-UI BiDi proof are outstanding Phase 0 spike work.
